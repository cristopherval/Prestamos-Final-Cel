Cómo funciona la Base de Datos

Esta aplicación guarda todo en el localStorage del navegador bajo la clave loanflow_db. La estructura es un objeto JSON con 3 "tablas" relacionadas entre sí.

// localStorage["loanflow_db"] → objeto con 3 tablas
TABLA: users[]
id string // Identificador único "u_..."
name string // Nombre del prestamista
password string // Hash de la contraseña
createdAt number // Timestamp Unix

TABLA: clients[]
id string // "c_..."
userId string // → referencia a users.id
name string // Nombre del cliente
phone string // Teléfono (opcional)
idCard string // Cédula/DNI (opcional)
address string // Dirección (opcional)

TABLA: loans[]
id string // "l_..."
userId string // → referencia a users.id
clientId string // → referencia a clients.id
amount number // Monto principal en Lempiras
rate number // Tasa de interés mensual (%)
frequency string // "weekly"|"biweekly"|"monthly"|"daily"
startDate string // "YYYY-MM-DD"
numInstallments number // Total de cuotas
installments array // Cuotas embebidas (ver abajo)

EMBEDDED: installments[]
idx number // Número de cuota (1, 2, 3...)
dueDate string // Fecha de vencimiento "YYYY-MM-DD"
principal number // Parte de capital de esta cuota
interest number // Parte de interés de esta cuota
amount number // principal + interest
balance number // Saldo pendiente después del pago
status string // "pending"|"paid"|"partial"
paidAt string // Fecha en que se registró el pago
paidAmount number // Monto abonado
notes string // Notas del cobrador

¿Por qué está relacionado? Un Usuario puede tener muchos Clientes. Un Cliente puede tener muchos Préstamos. Cada Préstamo contiene sus cuotas embebidas.

¿Es seguro? El localStorage es local al navegador. Nadie externo puede acceder a tus datos. Siempre ten un respaldo descargado por si el navegador borra sus datos.

Zona de Peligro

Borra permanentemente todos los clientes y préstamos de tu perfil actual. Los datos de otros usuarios no se verán afectados.
